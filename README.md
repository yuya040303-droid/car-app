# car-app

出張旅費精算アプリ（React + Vite）

出張の申請〜承認〜精算までのワークフローを扱う、楽々精算のようなモバイル向け出張旅費精算アプリです。

## 主な機能

- 出張申請の作成（行先・目的・期間・経費明細）
- 経費明細の登録（交通費・宿泊費・日当・その他）
- 日当の自動計算（設定画面で単価を変更可能）
- 申請一覧・ステータス絞り込み（下書き／申請中／承認済み／差戻し／精算済み）
- 承認者による承認・差し戻し（理由コメント付き）
- 承認済み申請の精算処理
- ユーザー切り替え（一般／承認者ロールのデモ用）

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
